outreach-scheduler

outreach-scheduler

Backlink outreach planning & scheduling system. Import harvested link data (WDC competitor-link products + similar datasets), build a classified pool, match projects by domain, generate configurable send plans, run them on a periodic schedule, and email a daily report.

Chinese version: see README.zh.md.

Status: functional layer shipped — import → probe → classify → match (human gate) → schedule → execute (HTTP form + CUA channel + wave2 SMTP) → daily report, with cron wiring. See DESIGN.md for architecture and docs for operations & the business roadmap.

Hard rules

  1. User data never enters the repo. data/, *.env, config/secrets* are gitignored; data_root may point outside the repo — but only to a folder named after this project (e.g. ~/outreach-scheduler-data/). Paths never reference other private folders. GitHub carries source code only.
  2. No external-toolchain dependency. Python3 stdlib + PyYAML + requests only; reads external product files, imports nothing from other systems.
  3. Captcha solving is CUA-first and free. Real-Chrome automation solves image/stealth challenges; paid solvers are optional and default-off.
  4. Pre-commit private scan. python3 tools/private_scan.py must pass before every commit; any hit blocks the commit (emails, passwords, private domains, private folder names, ~/ dot-folder and absolute home paths).
  5. Doc language. English-primary .md; Chinese translations in .zh.md.

状态：功能层已交付——import → probe → classify → match（人工闸）→ schedule → execute（HTTP 表单 + CUA 通道 + wave2 SMTP）→ 日报，含 cron 接线。架构见 DESIGN.zh.md，运维与业务路线图见 docs。

硬规则

  1. 用户数据永不进仓库。 data/、*.env、config/secrets* 全部 gitignore；data_root 可指向仓库外——但只允许以本项目命名的文件夹（如 ~/outreach-scheduler-data/），路径不得涉及其他私人文件夹。GitHub 只有源码。
  2. 无外部工具链依赖。 仅 Python3 标准库 + PyYAML + requests；只读外部产物文件，不 import 任何现有系统。
  3. 验证码走 CUA 免费通道。 本机真实 Chrome 自动完成图像/隐形挑战；付费打码可选、默认关闭。
  4. 提交前必跑私有扫描。 python3 tools/private_scan.py 必须通过，命中即拒绝提交（邮箱、密码、私有域名、私有文件夹名、~/ 点目录与绝对家目录路径）。
  5. 文档语言规范。 英文主文档 .md；中文翻译 .zh.md。
